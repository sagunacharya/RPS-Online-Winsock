# RPS Online - Winsock

A simple 2-player online Rock Paper Scissors game built using C++ and Winsock TCP networking.

## Features

- 2-player multiplayer
- TCP socket communication
- Client-server architecture
- Input validation
- Score tracking
- Draw detection
- First player to 3 points wins
- Simple console interface
- Supports localhost and LAN

## Requirements

- Windows
- C++ compiler (MinGW/G++ or MSVC)
- Winsock2

No external libraries are required.
